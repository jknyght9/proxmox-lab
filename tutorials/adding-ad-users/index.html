    Adding Active Directory Users

    Users can be added to the Samba AD domain via two methods: LDAP Account Manager (LAM) web UI or the samba-tool CLI.

    Method 1: LDAP Account Manager (LAM)

    LAM provides a web interface for managing AD users and groups.

    Accessing LAM

    Via DNS: 

    https://lam.<dns-suffix>

    Protected by Authentik forward auth (admin group required).

    LAM Login

    LAM uses a bind account (lam-admin) to connect to AD. The LAM master password is generated by Terraform and stored in Vault.

    Get the LAM bind password: 

    vault kv get -field=lam_bind_password secret/samba-ad/service-accounts

    On the LAM login page: - Select profile: lam - Enter the lam-admin password

    Creating a User

    1. Navigate to Users tab
    2. Click Create user
    3. Fill in:
    4. First name, Last name
    5. Username (sAMAccountName)
    6. Password (must meet domain complexity policy)
    7. Email (optional)
    8. Click Save

    Creating a Group

    1. Navigate to Groups tab
    2. Click Create group
    3. Enter group name
    4. Add members
    5. Click Save

    Method 2: samba-tool CLI

    Connect to the Samba AD container and use samba-tool directly.

    Accessing the Samba Container

    # SSH to nomad01, find the container
ssh labadmin@nomad01

# Find the DC01 container
CONTAINER=$(docker ps --format '{{.ID}} {{.Names}}' | grep 'samba-ad' | head -1 | awk '{print $1}')

# Open a shell
docker exec -it $CONTAINER /bin/bash

    Creating a User

    # Basic user
samba-tool user create john.doe 'SecurePassword123!'

# With full details
samba-tool user create jane.doe 'SecurePassword123!' \
  --given-name="Jane" \
  --surname="Doe" \
  --mail-address="jane.doe@mylab.lan" \
  --telephone-number="555-1234"

# Set password to never expire
samba-tool user setexpiry jane.doe --noexpiry

    Creating a Group and Adding Members

    # Create group
samba-tool group add "IT Admins"

# Add user to group
samba-tool group addmembers "IT Admins" jane.doe

# Verify membership
samba-tool group listmembers "IT Admins"

    Resetting a Password

    samba-tool user setpassword john.doe --newpassword='NewSecurePassword456!'

    Disabling/Enabling Users

    # Disable
samba-tool user disable john.doe

# Enable
samba-tool user enable john.doe

    Listing Users

    # List all users
samba-tool user list

# Show details for a user
samba-tool user show john.doe

    User Organization

    Organizational Units (OUs)

    The following OUs are created automatically during Samba AD deployment:

    OU Purpose
    CN=Users Default user container (service accounts)
    OU=Workstations Computer accounts for domain-joined workstations
    OU=Service Accounts Dedicated service accounts

    To create a custom OU for lab users:

    # Via samba-tool
samba-tool ou create "OU=Lab Users,DC=mylab,DC=lan"

# Move a user to the OU
samba-tool user move john.doe "OU=Lab Users,DC=mylab,DC=lan"

    Service Accounts

    The following service accounts are created automatically:

    Account Purpose Credentials location
    domain-join-svc Domain join operations for NAS/workstations secret/samba-ad/service-accounts
    authentik-sync Read-only LDAP bind for Authentik user sync secret/samba-ad/service-accounts
    lam-admin LDAP Account Manager bind account secret/samba-ad/service-accounts

    Do not delete these accounts. They are managed by Terraform.

    Authentik Sync

    If Authentik AD sync is configured (authentik_ad_sync: true in bootstrap.yml), users created in Samba AD are automatically synced to Authentik within the configured interval (default: 5 minutes).

    To trigger an immediate sync:

    1. Log in to Authentik admin (https://auth.<dns-suffix>)
    2. Navigate to Directory > Federation and Social login
    3. Find Samba AD source
    4. Click Run sync

    Or via the Authentik API: 

    API="https://auth.<dns-suffix>/api/v3"
TOKEN=$(vault kv get -field=api_token secret/authentik)

# Get source slug
curl -sk -H "Authorization: Bearer $TOKEN" "$API/sources/ldap/" | jq '.results[].slug'

# Trigger sync
curl -sk -H "Authorization: Bearer $TOKEN" \
  -X POST "$API/sources/ldap/samba-ad/sync/"

    Domain Password Policy

    The default Samba AD password policy requires: - Minimum 7 characters - Complexity enabled (uppercase, lowercase, digit or symbol) - No account lockout by default

    To view or change the policy:

    # View policy
samba-tool domain passwordsettings show

# Change minimum length
samba-tool domain passwordsettings set --min-pwd-length=12

# Enable account lockout after 5 failed attempts
samba-tool domain passwordsettings set \
  --account-lockout-threshold=5 \
  --account-lockout-duration=30 \
  --reset-account-lockout-after=5
